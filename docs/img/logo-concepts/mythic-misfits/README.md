# Mythic Misfits

Mythic Misfits is a monochrome campaign concept for `dn`: each character is
surrounded by the particular chaos of their software role, while the same
oversized headphones create a protected area of focus.

These PNG files are generated concept art, not production vector masters.
`campaign-contact-sheet.png` presents the complete first cast in a 2-by-2 grid.

## Shared visual system

- Front-facing bust on a square, warm off-white canvas
- One recurring, luxurious over-ear headset
- Role-specific noise contained in a 180-degree arc outside the headset
- Noise stops at the outer earcups and never radiates from them
- Calm negative space inside the headset boundary
- Role cues expressed through silhouette, clothing, and abstract motion

## First cast

| Asset                         | Role                    | Noise metaphor                                                |
| ----------------------------- | ----------------------- | ------------------------------------------------------------- |
| `buff-alien-engineer.png`     | Software engineer       | City chatter, traffic, music, and interruptions               |
| `cyclops-product-manager.png` | Product manager         | Competing stakeholder paths and changing priorities           |
| `sphinx-product-designer.png` | Product designer        | Conflicting curves, grids, spacing, and hierarchy             |
| `minotaur-sre.png`            | SRE / platform engineer | Incident escalation, load surges, and cascading interruptions |

The buff alien is the campaign anchor. The Cyclops, Sphinx, and Minotaur extend
the same visual grammar without becoming alternate primary logos.
